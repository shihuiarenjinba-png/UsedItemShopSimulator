# 開業モードの保存・借入返済機能 — 実装記録（2026-10-18）

開発ブランチ: `feature/onboarding-debt-workshop-spec-20261018`

## 実装済み（GitHub）
- **初回の開業画面**：誰のお金で始めるかを3択で選ぶ。開業ボタンを押すまでは営業できず、未選択の通常セーブは生成されない。
- **モードの固定**：確定時に `finance.mode` をセーブ内に保存。通常の営業画面に変更ボタンは出さない。再読み込み後も同じモード・借入残高で継続。
- **リセットだけは選び直せる**：新規開始を確認すると、旧セーブを `used-item-shop:previous-run:v1` にバックアップしてから現行セーブを消し、再びモード選択画面へ戻る。保存失敗ならリセットを中止する。
- **前回のプレイを復元**：経営記録内の「前回のプレイを復元」でバックアップを検証して切り替え。破損データで現在のセーブを上書きしない。
- **イージー**：友人から70万円、利息0、返済任意。
- **ノーマル**：母から70万円、利息0、180営業日までの返済目標。
- **ハード**：70万円の借金、30営業日ごとに未返済元金の1%、180営業日までの返済目標。未払利息への複利なし。
- **会計**：開業時現金70万円・負債70万円、純資産0円。返済操作は元金・未払利息を減らし、営業日を進めない。利息発生日は損益を減らすが、現金は返済時だけ減る。
- **資金・返済画面**：元金、未払利息、手元現金、在庫/機材の簿価目安、純資産、次の利息日、期限、返済額入力、一部返済、全額返済。
- **チュートリアル**：初回資金選択と営業ルールをまとめて説明。買取、倉庫・修理、営業、返済それぞれに折りたたみ式の「？」ガイドを配置。
- **旧セーブ**：旧 `v1` は新たな負債を付けず「旧ルール」で継続。セーブの形式は変更しておらず、新しいゲームだけ `finance` オブジェクトを追加。
- **独立JavaScript回帰**：計63件成功。新規 finance 9件、GUIに保存・リセット/復元など5件を追加した。これは**Node実行・Windows実機試験ではない**。
