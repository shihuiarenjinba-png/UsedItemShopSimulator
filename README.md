# UsedItemShopSimulator — 交渉と値付けで育てる中古品店

**GitHub開発版 / Microsoft Store販売HOLD。** main・過去のリリース・ユーザーのセーブは保護しています。

## ゲームの狙い
「売り手と値段を交渉し、修理した商品をいくらで売るか決め、ゆっくり買い手を待つ」買い切り・オフライン経営ゲーム。**現実時間では経過せず、自分で1日営業するときだけ時間が進みます。**

## 簡単な3ステップ
1. 持ち込み品の希望額を見る。「希望額で買う」または「価格を交渉する」を選び、販売価格を決める。
2. 買い取った品は倉庫に保管。修理台で整備し、売場に並べて値付けする。商品は少しずつ摩耗する。
3. 1日営業して、時間ごとの来客と購入結果、買取成否、利益、売れ残りを確認。

**価格交渉**は提示額により成功率が変わります。失敗時は初期設定では買えません。ただし本人が事前に指定した場合は希望額、または希望額+約6%で購入できます。勝手な追加支出はありません。

**需要と販売速度**は商品別の価格弾力性、現在の評価額、状態、評判、日々の需要変動で決まります。価格が高ければ売れないこともあります。来店客は営業日ごとに変化し、1人につき最大1点を購入します。毎日の販売は在庫・売場・来客人数の制約を受け、実際の売却を保証しません。

初期商品はカメラ・ゲーム機・オーディオ・希少本。21営業日以降、まれに中古車の高額取引が追加されます。商品の摩耗は緩やかな日次価値低下と数十日ごとの状態変化でモデル化し、修理で状態を改善できます。すべて架空の経済設定です。

新仕様の詳細：`docs/VISITOR_WAREHOUSE_PRICING_MODEL_20261018_JA.md`。売り手の事情に合わせた緩やかな交渉確率、店内人物タイプと来店時刻、倉庫→修理台→売場、65,000円の機材投資、仕入/保管/家賃/機材回収を考えた採算ライン目安を追加しました。人物の本格2Dイラストはまだ未実装です。
