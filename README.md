# UsedItemShopSimulator — 仕入れと値付けで育てる中古品店

**GitHub feature開発版・Microsoft Store販売HOLD。** mainはリポジトリ初期化用READMEのみで保護する。

買い取り希望のカメラ、ゲーム機、オーディオ、希少本を見て、買い取るか・いくらで売るかを判断する店舗経営ゲームです。商品の状態と価格が販売確率に影響します。現金、家賃、売れ残り、在庫、評判も計算します。

## 操作
1. 今日の持ち込み品を選び、店頭価格を設定
2. 在庫の販売価格を見直す
3. 1日営業して、売上・利益・売れ残りを確認

詳細なセーブ・12日分の履歴は折りたたみ。端末内に自動保存し、セーブ異常時は元データを上書きしません。

Node.js 20以上で `npm test`。ブラウザで `index.html` を開くとオフラインの初期プレイ画面が起動します。GUI・Windowsパッケージの完走確認はまだ未実施。

## 商用化の残課題
商品の鑑定難易度、修理、買取交渉、お店の改装・従業員、イベント、顧客の嗜好、長期バランス、ゲームとしての達成感、WindowsのMSIX・WACK・実機GUI・権利・価格・商品ページ。初期版を完成版として販売しない。
